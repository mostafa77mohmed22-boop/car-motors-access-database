## قبل الرفع

- تأكد من أن ملف Microsoft Access مغلق.
- لا ترفع بيانات شخصية أو حقيقية للعملاء أو الموظفين في مستودع عام.
- إذا احتوت القاعدة على بيانات حقيقية، أنشئ نسخة تجريبية ببيانات وهمية قبل الرفع.
- ارفع الملف من GitHub عبر: **Add file → Upload files** ثم اختر ملف `.accdb`.
